# helm wiki

helm lets you run coding agents (Claude Code and Codex) on your GitHub projects and keep an eye on all of them from one window. It runs as a desktop app, in your browser, and as a phone app.

Website and downloads: [takethehelm.dev](https://takethehelm.dev)

## Start here

Pick the path that sounds like you.

### I have an idea and don't know git
You do not need to. Chat with an agent about your idea, ask it for a brief, then let an agent build it.
1. [Getting started](Getting-Started.md): install helm and run your first session.
2. [Free agents](Free-Agents.md): the chat-first way to start, with no repository needed.
3. [Glossary](Glossary.md): plain-English meanings for words like branch, diff and pull request.

### I write code and want to stay in control
Every session works in its own copy of your project on its own branch. Nothing touches your checkout until you say so.
1. [Core concepts](Core-Concepts.md): sessions, worktrees and branches.
2. [Changes and review](Changes-and-Review.md): read the diff hunk by hunk, accept, ask or reject.
3. [Safety and limits](Safety-and-Limits.md): permissions, budgets and what agents can and cannot do.
4. [Pull requests and merging](Pull-Requests-and-Merging.md).

### I run lots of agents at once
1. [Overview and Needs you](Overview-and-Needs-You.md) and the [Inbox](Inbox.md): see what is working and what is waiting on you.
2. [Extra agents and subagents](Extra-Agents-and-Subagents.md) and [Checkpoints and Compare](Checkpoints-and-Compare.md): put several agents on one task and keep the best run.
3. [Automations](Automations.md): start agents from a schedule or a GitHub event.
4. [Reports](Reports.md), [Safety and limits](Safety-and-Limits.md) and [Keyboard shortcuts](Keyboard-Shortcuts.md).
