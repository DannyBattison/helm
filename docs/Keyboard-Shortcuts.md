# Keyboard shortcuts

Everything in helm can be reached from the keyboard. **Cmd** on a Mac is **Ctrl** on Windows and Linux (written **Mod** in Settings).

> **In short**
> - **Cmd/Ctrl+K** searches everything. **Alt+1** to **Alt+4** jump between pages.
> - Change any shortcut, or add your own, under **Settings, then Keyboard shortcuts**.

## Defaults

| Shortcut | Action |
| --- | --- |
| **Mod+K** | Search sessions, repositories, conversations, commits and code, and run commands |
| **Mod+N** | New session |
| **Alt+N** | New session (for browsers that keep Mod+N for a new window) |
| **Mod+Shift+N** | New session in the repository you are on |
| **Alt+1** | Go to Overview |
| **Alt+2** | Go to Inbox |
| **Alt+3** | Go to Needs you |
| **Alt+4** | Go to Activity |
| **Alt+A** | Jump to the next session that needs you, going round the list |
| **Alt+Up** / **Alt+Down** | Previous / next session in the list |
| **Mod+,** | Open Settings |
| **Mod+Shift+X** | Interrupt all agents (the emergency stop) |
| **Mod+Shift+E** | Resume all agents |
| **Ctrl+`** | Show or hide the terminal |
| **Mod+P** | In the Code tab: open a file by name |
| **Mod+S** | In the Code tab: save the file |

## Inbox keys

Inside the [Inbox](Inbox.md): **j**/**k** move, **a** approve, **A** always allow, **d** deny, **n** deny with a note, **1** to **9** answer, **c** continue, **r** resume or retry, **x** cancel, **s** start, **Enter** open.

## Terminal keys

**Ctrl+Shift+T** new tab, **Ctrl+Shift+W** close, **Ctrl+Tab** or **Ctrl+PageUp/PageDown** switch tabs, **Ctrl+Shift+F** (**Cmd+F** on a Mac) search. See [Code and terminal](Code-and-Terminal.md#the-terminal).

## Messages

**Enter** sends and **Shift+Enter** adds a line, or the reverse if you choose **Cmd/Ctrl+Enter** in [Settings](Settings.md#agents). **Esc** interrupts a working agent (or **Esc twice**, or **Button only**, as you prefer).

## Change a shortcut

1. **Settings, then Keyboard shortcuts**.
2. Click an action, press the new combination. helm warns if it clashes with another.
3. **Reset all** goes back to the defaults.

## Custom shortcuts

Under **Custom shortcuts**, add your own: **Start a new session** (with a repository, model and so on preset) or **Go to a page** (Overview, Needs you, Inbox, Activity, Archive, Reports, Settings, a repository or one of its tabs). Give it a label and a key combination.
