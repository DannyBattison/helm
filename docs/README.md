# helm documentation

The user documentation for helm, written for everyone from people who have never used git to people running a dozen agents at once.

Start at [Home](Home.md). The same pages are published to the repository's GitHub wiki by `.github/workflows/wiki.yml`.

- Writing or editing pages: [Contributing to the docs](Contributing-to-the-Docs.md) and the [style guide](STYLE.md).
- Files starting with `_` (`_Sidebar.md`, `_Footer.md`) are wiki navigation. `README.md` and `STYLE.md` are not published.
