# Artifacts

Files an agent hands back to you: a chart, a report, a generated image, an export.

> **In short**
> - Agents drop a file in the chat as a link or inline image.
> - Images show in the conversation; click to enlarge. Other files get a download button.
> - New ones wait in your [Inbox](Inbox.md) until you dismiss them.

## How they appear

An agent writes a file into a folder helm made for the session and links it in its reply. In the conversation:
- **Images** (PNG, JPEG, GIF, WebP, SVG, AVIF) are shown inline with a download button. Click to open larger.
- **Other files** appear as a download button.
- Each new one also appears in the Inbox as **File for you**.

The same works in the desktop app, the browser and on a phone. Files up to 25 MB can be downloaded in the chat; very large ones say so.

An artifact is kept as long as the session exists. If the computer cleaned its temporary folder, the chat says the artifact has expired.

## Artifacts and fixtures

- **Artifacts** are what agents produce for you.
- **Fixtures** are files you upload for agents to use. See [Repository page](Repository-Page.md#fixtures).

Files you drop on a session's message box that are not images become fixtures of its repository, not artifacts.

## Uploading to the repository

Artifacts can be uploaded into the repository, in chunks that resume if interrupted, for things you want to keep with the project.
