## D-157 · 2026-10-26 · Terminal: tabs, quick jump, search, and a shell that starts where you are
The terminal drawer has tabs (Ctrl+Shift+T new, Ctrl+Shift+W close, Ctrl+Tab / Ctrl+PageUp/Down switch, middle-click closes). Tabs and their shells stay alive when the drawer is minimised or you navigate; closing the last tab closes the drawer. A new tab starts in the open session's worktree, or the repository's checkout on a repository page, otherwise the home folder (a repository page used to start in home). The lightning button is quick jump: it lists this workspace, repositories, live sessions and home, and types `cd` into the current shell; the caret next to + opens a new tab in any of them. Added xterm search (Ctrl+Shift+F, Cmd+F on mac), clickable links (`@xterm/addon-web-links`, `@xterm/addon-search`), 10,000 lines of scrollback, tab titles from the shell, a restart bar when a shell exits, and a draggable drawer height. Tab completion and history come from the real shell. When the pty module does not load, helm now uses `script` for a real pty on macOS/Linux instead of the old echo-only line mode, which could only run one command at a time. Not run in the app here; typecheck of the app and desktop passes, vitest crashes in this sandbox.
Why: user request.
