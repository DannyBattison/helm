## 2026-11-11 · Pull request titles and descriptions are summarised, from a template or the agent

A new pull request's title is no longer the task cut to 72 characters, and the description no longer repeats the task. Settings → Pull request template (`prAi`, `prTitleTemplate`, `prBodyTemplate`, also settable per repository) offers two modes. Template mode fills `{{commit}}` (first commit subject, the task when there are none), `{{commits}}`, `{{count}}`, `{{task}}`, `{{branch}}`, `{{base}}`, `{{files}}`, `{{stats}}`, `{{issue}}` using the same `{{name}}` syntax and empty-line rule as message templates; the defaults are `{{commit}}` and the commit list, stats and issue. Agent mode (`writePr`) runs the session's backend `review` call read-only with a title/body schema, costs tokens, and runs only when the pull request form is shown (once per set of commits, with a button to redo it) or when creating one for an extra repository.
While a pull request is open, helm keeps refreshing the helm block from the template as in D-152, but never in agent mode, so pushes do not spend tokens. Supersedes the title and description wording in D-152.
Why: user request; the task text read badly as a title and made a poor description.
