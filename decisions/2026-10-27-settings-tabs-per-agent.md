## 2026-10-27 · Settings has a generic Agents tab and one tab each for Claude Code and Codex
Agents holds what applies to every agent: default model, permission mode, always-allowed commands, sessions at once, subagent limits, auto push, commit author and the like, with a line showing which agents are ready. Claude Code holds its account, command-line path and version, billing (subscription or API tokens) and Remote Control. Codex (OpenAI Codex, signed in with a ChatGPT plan or an OpenAI API key) holds its account, command-line path and version, how it is billed, its plan usage, how the permission modes map onto its approval policy and sandbox, and what it does not support. Usage keeps the shared parts: plan meters for every agent paid for by a plan, the pause and warn percentages, and dollar budgets for any agent paid per token.
Why: user request, so agent-specific settings are not mixed into the general ones.
