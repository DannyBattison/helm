## 2026-10-27 · MCP servers, global and per repository

helm keeps its own list of MCP servers: global ones in settings, and per-repository ones on the repository record (Settings → MCP servers, and an MCP servers tab on each repository). Sessions get both through the SDK's `mcpServers` option when the agent starts; a repository's server replaces a global one of the same name, and a disabled one is left out (so a disabled repository entry can switch a global server off there). They can be added, edited, enabled/disabled and removed. Reason: Claude Code's own `.mcp.json` / `~/.claude.json` are not managed by helm and cannot be edited from it; keeping them in helm's store lets them sync and be edited in one place. Changes apply to sessions started afterwards. Review-only runs and free agents get only the global servers (free agents) or none (reviews).
