## D-133 · 2026-10-26 · Artifacts can be uploaded to a repository and are copied into every session's worktree, uncommitted
Settings → "Artifacts" lets you upload artifacts (up to 25 MB each) per repository. They are kept in helm's data folder (`repo-artifacts/<repo>`), copied to the top of each worktree when a session is created, and copied again (only where missing, so the agent's edits are kept) when an agent starts, so older worktrees get later uploads. Each name is added to the worktree's own `info/exclude`, so they never show in changes or get committed; a file the repository already tracks is never overwritten. Names are single path segments only. It complements the "copy ignored files" setting, which only copies what already exists in your checkout. Free agents are not covered. Typechecked and unit-tested, not run in the app.
Why: user request, for secrets, data and notes that should not be committed but every agent needs.
