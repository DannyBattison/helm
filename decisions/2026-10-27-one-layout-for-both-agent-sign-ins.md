## 2026-10-27 · Claude and ChatGPT sign-ins share one layout, each with its copy button
Both flows are the same two numbered steps. Step 1 opens the sign-in page, with a Copy link button for when the tab does not open (or the page is wanted on another device). Step 2 is what differs by direction: Codex gives a code to enter on its page, shown large with a Copy code button, and helm carries on by itself once ChatGPT confirms; Claude shows its code on its own page for you to bring back, so its step has a field with a Paste button (reads the clipboard) and Continue. Both can be cancelled. The steps are one component, `SignInSteps`, so they cannot drift apart.
Why: user request. Claude's code comes from Claude to you, not from helm, so it has a Paste button where Codex has Copy code.
