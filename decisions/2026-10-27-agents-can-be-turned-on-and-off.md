## 2026-10-27 · Claude Code and Codex are switches on the Agents tab, and at least one is always on
`Settings.enabledAgents` lists the agents in use (both by default). A switch that is off leaves that agent out of every model list, plan meter and default, and blocks new sessions, comparisons and automations on it; sessions it already has keep working and can be resumed. `BackendInfo` now tells being set up (`configured`: installed and signed in) from being turned on (`enabled`); `ready` is both. An agent that is not set up says why and links to its tab under Accounts, and the switch can still be changed. The last agent that is on cannot be switched off (the switch is disabled, and the server refuses it too), and turning off the default agent moves the default to one that is on. With nothing ready, the new-session dialog says to set one up.
Why: user request.
