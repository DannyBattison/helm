## 2026-10-26 · Automated agents can watch one branch, and start on new commits
An automated agent has an optional branch. It narrows workflow-run triggers to runs on that branch and pull request and merge triggers to pull requests that target it; empty means any branch. Issues and schedules ignore it. A new trigger, "When commits are pushed to a branch", polls the branch (the default branch when none is chosen), records the first look, and starts one session per poll for all commits that arrived together (the prompt's `{{title}}` is the latest commit message; the task says how many arrived). Seen commit hashes are kept per branch. Commits on branches of automated-agent sessions are skipped, as for the other triggers. The editor offers the repository's branches for a single repository and free text for a global agent.
Why: user request, to watch a specific branch such as `release` or `main`.
