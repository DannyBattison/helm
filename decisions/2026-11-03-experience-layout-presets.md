## 2026-11-03 · Experience layout presets

Offer Simple, Standard and Advanced in Appearance, defaulting to Advanced for new and existing installations. Simple emphasizes tasks and review; Standard adds normal developer navigation; Advanced retains all metrics, board layout and session controls. Reduced navigation and settings have explicit show-all controls and command search keeps destinations accessible. Presets only affect presentation: permissions, budgets, existing sessions and saved Overview layout are preserved. Settings search includes sections hidden by a preset.
