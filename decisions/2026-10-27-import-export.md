## 2026-10-27 · Import and export for migrating servers
Settings has an "Import and export" section. Export writes one JSON file (`src/core/migrate.ts`) with the state in `helm.json` (minus `user`), transcripts, the activity log and repository artifacts. It leaves out the `*.bin` secrets (GitHub token, Claude/companion key, email password), caches and logs. Import is additive: records whose id already exists are kept, files already on disk are not overwritten, and machine-specific settings (paths, shell, update, companion URL, tray) keep the destination's values. Imported running sessions come in idle; ones whose worktree is missing here are flagged `worktreeGone`. The browser reads the file and sends its text, so the same call works on desktop and hosted; the hosted WebSocket limit rose to 512 MB for it.
Why: user request. Merging never destroys data on the destination, and secrets are re-entered rather than carried in a file.
