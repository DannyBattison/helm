## 2026-10-29 · The mobile app is a Capacitor project; UDP and the background task are native, everything else is TypeScript

Builds on [2026-10-29-phone-app-reaches-desktops-over-an-encrypted-udp-link](2026-10-29-phone-app-reaches-desktops-over-an-encrypted-udp-link.md) and [2026-10-29-phone-notifications-by-background-polling-and-qr-pairing](2026-10-29-phone-notifications-by-background-polling-and-qr-pairing.md). `mobile-app/` (Capacitor 7, own `package.json`, `android/` and `ios/` projects committed as Capacitor expects) wraps the shared renderer. The page it opens first is plain DOM (`src/main.ts`): the list of instances, adding a computer by QR or paste with the GitHub check, adding a hosted server. A computer is then opened by mounting the renderer over `createConnectionBridge(connectDesktop(…))`; a hosted server is opened by navigating the web view to its `/mobile/` page, which keeps its own cookie sign-in (a native origin cannot use that server's same-origin WebSocket and cookies), so there is no in-app way back from it except the Android back button.

Native code is kept to what a web view cannot do, in both languages: a UDP socket (`HelmUdp`, plugin `HelmUdpPlugin`; one dual-stack socket, base64 datagrams) and the background task (WorkManager on Android, `BGAppRefreshTask` on iOS). The task does not reimplement the protocol: it starts a hidden web view on the app's own `collect.html`, which runs the same TypeScript `collect()` against a small injected `HelmHeadless` object (preferences, UDP, notify, done), then shows notifications natively. The instance list is read from the same Preferences store the app writes (`CapacitorStorage`).

Unwritten risk, said plainly: no Android SDK or Xcode was available, so the Java and Swift, the Xcode project edits (four files added by hand), the storyboard and plist changes have never been compiled. A GitHub workflow (`mobile-android.yml`, manual) builds a debug APK so the Android build can be tried without Android Studio. Found while wiring it: IPv6 addresses are spelled differently by Java, Swift and the share code, so the joiner now compares addresses in one canonical form (`sameHost`), tested.

Why: user request ("do it, include build scripts"). The root `package.json` has `mobile:*` scripts; CI installs `mobile-app`'s packages for the typecheck.
