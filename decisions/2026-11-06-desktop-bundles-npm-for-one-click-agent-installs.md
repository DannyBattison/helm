## 2026-11-06 · The desktop app bundles npm and installs Codex, Qwen Code and Ollama with one click
`npm` is a dependency of the desktop app (about 19 MB, unpacked from the asar), run on Electron's own Node, so no Node install is needed. Codex and Qwen Code are installed into `<data dir>/tools` with `--ignore-scripts`, started from the script named in their package.json `bin` through Electron's Node, and their path settings are pointed at it; an Update button appears for tools helm installed (`BackendInfo.managed`). Ollama runs its own installer after a confirmation that shows the command (`install.ps1` on Windows, `install.sh` elsewhere). On Linux that installer needs `sudo`, which helm cannot ask for, so without passwordless sudo helm shows the command to run in a terminal; on a Mac the app is used from `/Applications` if linking the command needs a password. Programs are found in the usual install folders as well as the PATH, so a fresh install works without restarting. Hosted has no `host.npmCli` and no buttons. Verified for real: both npm installs work and run under Node; Qwen Code's ACP handshake matches what the backend expects.
